# PRD: market-settlement

## 문제
소규모 마켓에서 판매자별 주문·환불·수수료를 수작업으로 정산하면 오류가 나고 시간이 든다. 인기 상품 선착순 구매에서는 재고가 어긋난다.

## 사용자
- 구매자: 상품 조회, 주문, 결제, 환불 요청
- 판매자: 상품·재고 등록, 주문 확인, 정산 내역 조회
- 운영자: 수수료율 설정, 정산 실행·검수

## MVP 범위
1. 회원/판매자 가입과 인증 (JWT)
2. 상품·재고 관리, 상품 조회 (Redis 캐시)
3. 주문 → PortOne 테스트 결제 → 환불
4. 선착순 상품 구매 (Redis 재고 선점, 요청 제한)
5. 일 정산 배치: 판매자별 매출 − 환불 − 수수료 = 정산액, 이력 보관
6. 판매자 정산 조회, 운영자 정산 승인
7. 최소 화면 (React): 상품 목록, 주문, 판매자 정산 조회

## 제외 범위
- 배송, 리뷰, 쿠폰/프로모션, 실제 계좌 이체, 다중 PG 연동
